# 👁️ Animal Vision Simulator - Android & Web App

A full-stack, real-time WebGL shader and AI-powered Android application that simulates how different species (Dogs, Cats, Eagles, Mantis Shrimp, Snakes, Bees, Owls, Bats, Deep-Sea Fish, etc.) perceive the world.

## ✨ Features Included

1. **Real-time Live Camera Shader Filters**:
   - Dichromatic (Dog / Cat / Horse vision)
   - Tetrachromatic & Ultraviolet UV fluorescence (Eagle, Bee, Mantis Shrimp)
   - Thermal Infrared Heatmap (Pit Viper snake sensing body heat)
   - Night Vision & Tapetum Lucidum amplification (Owl, Feline)
   - Echolocation sonar visual rendering (Bat)
   - Bioluminescent Deep-Sea Vision (Giant Squid, Lanternfish)
   - Compound Eye Facet Grid Shader (Insect / Dragonfly)

2. **Full Animal Encyclopedia & Interactive Comparisons**:
   - Detailed biological optic metrics: Cone types, rod density, FOV (Degrees), spectral range (nm), flicker fusion rate (Hz).
   - Side-by-side split screen slider comparing Human Vision vs. Animal Perception.

3. **14 Interactive Educational Arcade Games**:
   - Match-3 Optics Puzzle
   - Block Blast Visual Challenge
   - Thermal Pit Snake (Classic Snake with infrared tracking)
   - Animal Vision Endless Runner (Switch vision modes to dodge dark obstacles)
   - 4x4 Optics Mini Sudoku
   - Photoreceptor Merge 2048
   - Spot the Dichromatic Difference
   - Guess the Animal Vision Filter
   - Jigsaw & Tile Sliding Puzzles
   - Optics Word Search & Tic-Tac-Toe

4. **Server-Side Gemini AI & Voice Assistant**:
   - Multi-modal visual sight analysis (`@google/genai`)
   - Comparative Vision AI Querying & Quiz Generator
   - Web Speech API TTS & Voice Query response

5. **Gamification, Profile, & Persistence**:
   - User Accounts (Email Auth & One-click Guest Mode)
   - XP, Leveling, Coin Rewards, Daily Login Streaks, & Badges
   - High Scores & Global Leaderboards
