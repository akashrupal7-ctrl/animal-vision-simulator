# 👁️ Animal Vision Simulator

An interactive WebGL shader and AI-powered web and mobile application that simulates how different species perceive the world in real time.

---

## 📱 Features

- **10 Real-Time Shader Vision Filters**: Dichromatic (Dogs/Cats), Tetrachromatic & UV (Eagles/Bees), 16-Cone Spectrum (Mantis Shrimp), Thermal Infrared (Pit Vipers), Night Vision Tapetum Lucidum (Owls), Echolocation (Bats), Bioluminescence (Deep-Sea Fish), and Compound Eye Matrix (Insects).
- **14 Arcade Mini-Games**: Match-3, Block Blast, Memory Match, Thermal Snake, Vision Runner, 4x4 Sudoku, 2048, Word Search, Sliding Tile, Spot Difference, Jigsaw, Tic-Tac-Toe, Vision Challenge, and Quizzes.
- **Server-Side Gemini AI**: Visual sight breakdown, comparative optics analysis, and trivia generation using `@google/genai`.
- **Capacitor 8 Mobile Integration**: Native Android camera permissions, haptics, and mobile UI responsiveness.

---

## 🚀 Quick Start (Web Development)

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production assets & sync Capacitor Android project
npm run build
```
